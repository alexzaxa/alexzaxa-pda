License key library

built, not yet proven

Kleidi · Κλειδί · the key

Kleidi: the reusable version of the PDA's license system, for whatever I build next.

The PDA's license system, with the restaurant software peeled off.

AlexZaxa Solutions issues offline-verified license keys bound to the activating machine — that logic used to live inside the PDA codebase alone. Kleidi is the same scheme pulled into its own small library, so the next thing I license doesn't start from zero. Hasn't licensed anything but the PDA yet.

  • Same offline verification and machine-binding scheme the PDA runs in production
  • Not yet wired into a second product

LiteVoice: a simple voice chat app I built — not yet tested with a real call.

A voice channel that doesn't need everything else Discord comes with.

A lightweight, voice-only alternative: a C# client talking to a relay server running on Ubuntu. No text channels, no bots, no screen share — just a room and the people talking in it. Written end to end; it hasn't carried a real call yet.

  • C# desktop client paired with a dedicated Ubuntu relay server
  • Next milestone is a real multi-person call, not another unit test

built, not yet proven

Dokimi · Δοκιμή · the trial

Dokimi: tests a trading strategy against real price history before paper money touches it.

Every strategy loses on history before it's allowed near paper money.

A backtester that replays a trading strategy against real historical price data before the trading bot's paper gate even opens. Written and runs end to end — I just haven't fed it a strategy worth trusting yet, so it has nothing to report.

  • Replays historical price data against a strategy before paper trading starts
  • Outputs the same risk metrics the live gates will eventually check
